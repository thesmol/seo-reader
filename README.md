# seo-reader — задание №8

Практические работы по дисциплине «SEO — оптимизация портальных решений».

Здесь находится часть №8 с чтением книги, подгрузкой глав вверх/вниз и сохранением главы. Котировки: [seo-bitcoin](https://github.com/thesmol/seo-bitcoin).

## Публикации и исходники

- №8: [GitHub Pages](https://thesmol.github.io/seo-reader/), исходники в корне репозитория.

Каждая папка этапа содержит свои ресурсы и не требует файлов последующих заданий.

## Локальный запуск

```sh
npm ci
npm run dev
```

Откройте адрес, показанный Vite (обычно `http://127.0.0.1:5173/`). Для AJAX и XML используйте HTTP, а не `file://`.

Для сборки и проверки статической публикации:

```sh
npm run build
npm run preview
```

Нужен Node.js 20.19+ или 22.12+. Сборка Vite сохраняет исходные HTML, CSS, JavaScript, XML и медиа без изменения: это важно для сравнения размеров jQuery, AMP-валидации и самостоятельности этапов. Для замеров используйте `preview`, потому что `dev` добавляет служебный клиент Vite.

Возможное кеширование данных при повторных обращениях к одному и тому же url-адресу.

        Ссылка на актуальный курс США к рублю: https://www.cbr-xml-daily.ru/daily_json.js.

    Сохранение и восстановление состояния ajax-приложения.

Приложение: addons/task8/...
